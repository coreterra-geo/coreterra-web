## 🛠️ Stack Teknologi

| Komponen | Teknologi | Deskripsi / Penggunaan                                       |

| **Bahasa Pemrograman**| TypeScript 5.x | Keamanan tipe data (*Type Safety*), antarmuka (*Interface*)  |
